# lib-fetch-js

`fetch` over the generated WebIDL bindings — JS-host counterpart of
`fetch-c`. The bindings are sdkgen output under `handl-packages/generated/`
(a gitignored build artifact), regenerated from the committed spec
`specs/fetch.idl` (w3c/webref @ 19e2457df856a43ec749c0fd4e88ae1edc4f6cb8,
`ed/idl/fetch.idl`).

Part of the `handl-lang` org split (ADR-0128). History is a `git subtree
split` of the platform monorepo's `fetch-js/` (via `web`).

## Layout

```text
src/        the .hnl sources
specs/      committed sdkgen input (fetch.idl)
handl-packages/generated/   build artifact — regenerated by the gate
pkg.hnl     dependencies, when any: `{ deps: { <name>: "branch:<ref>" } }`
```

## Regenerate

```bash
hnl sdkgen webidl specs/fetch.idl --output handl-packages/generated/fetch
```

## Gate

```bash
HNL=../host-cli/target/debug/hnl scripts/hnl-gate.sh
```

The gate regenerates `handl-packages/generated/` from `specs/` first, then
typechecks/lints/tests whatever `.hnl` sources exist.
